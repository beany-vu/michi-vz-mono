# michi-vz brand policy

The michi-vz **source code** is licensed under the MIT License (see [LICENSE](LICENSE)).
The **brand** is not part of that grant:

- the name **michi-vz** and the **@michi-vz** npm scope,
- the **Michi shield logo**,
- the **cat artwork** used on the documentation site (including the homepage cat band and
  the social-card image).

These identify the canonical project and remain all rights reserved.

## What this means in practice

- **Contributing forks are welcome.** A GitHub fork made to open a pull request is the normal
  flow and needs no changes.
- **Redistributed or independently maintained forks must rebrand.** Use a different name, do
  not publish under the `@michi-vz` npm scope, and remove the logo and cat artwork.
- **Referring to the project by name is fine** - articles, tutorials, package lists, and
  dependency credits are encouraged.
- **The canonical distribution** is the `@michi-vz` packages on npm and the documentation at
  <https://michi-vz.netlify.app>.

Questions about brand use: open an issue at
<https://github.com/beany-vu/michi-vz-mono/issues>.
